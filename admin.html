    Printing checklist
    1. Letter glossy photo paper, with the printer's paper type set to glossy photo.
    2. Scale 100% or Actual size. Turn off Fit to page.
    3. Print the same way you print the Canva template. If you use borderless, check the next step carefully, because borderless can stretch the picture.
    4. The line at the bottom of every sheet should measure exactly 2 inches.
